# Modern Journal - iOS 26

A beautiful, AI-powered journaling app built with Xcode 26, Swift 6, and iOS 26. Capture your thoughts, track your mood, and gain insights into your writing patterns with advanced AI analysis.

## ✨ Features

### 📝 **Journaling Features**

- **Rich Text Editor** - Write and edit your journal entries with ease
- **Mood Tracking** - Track your emotional state with 9 different moods
- **Tag System** - Organize entries with custom tags
- **Search & Filter** - Find entries by content, mood, or date
- **Favorites** - Mark special entries as favorites
- **Statistics** - View your writing patterns and insights

### 🤖 **AI-Powered Insights**

- **Sentiment Analysis** - Understand the emotional tone of your entries
- **Topic Extraction** - Automatically identify key themes
- **Writing Style Analysis** - Get insights into your writing patterns
- **Smart Suggestions** - Receive personalized writing recommendations
- **Reading Time** - Calculate estimated reading time for entries

### 🎨 **Liquid Glass Design**

- **Modern UI** - Beautiful `.glassMaterial` backgrounds
- **Multiple Themes** - Choose from 6 stunning themes
- **Dynamic Gradients** - Smooth, reflective interfaces
- **Smooth Animations** - Fluid transitions and interactions

### 🚀 **Modern iOS 26 Features**

- **Swift 6** - Latest concurrency and language features
- **Enhanced SwiftUI** - Modern declarative UI framework
- **Voice Control** - Voice-to-text capabilities
- **Data Persistence** - Secure local storage with UserDefaults
- **Export/Import** - Backup and restore your journal data

## 📱 **App Structure**

### **Tab Navigation**

1. **Journal** - Home screen with quick stats and recent entries
2. **Entries** - Browse, search, and filter all your journal entries
3. **Stats** - View detailed statistics and insights
4. **Settings** - Customize themes, AI features, and data management

### **Key Views**

- **JournalHomeView** - Dashboard with stats and quick actions
- **EntriesListView** - Searchable list of all entries
- **NewEntryView** - Rich text editor for creating entries
- **EntryDetailView** - Full view of individual entries with AI insights
- **StatsView** - Comprehensive statistics and analytics
- **SettingsView** - App configuration and preferences

## 🛠 **Technical Architecture**

### **Data Models**

- **JournalEntry** - Core entry model with title, content, mood, tags
- **Mood** - Enum with 9 emotional states and visual representations
- **AIInsights** - AI analysis results including sentiment and topics
- **JournalStats** - Comprehensive statistics and analytics
- **JournalSettings** - User preferences and configuration

### **Manager Classes**

- **JournalManager** - Central data management and AI processing
- **AIService** - AI-powered analysis and insights generation
- **VoiceControlService** - Voice-to-text functionality

### **Design System**

- **Liquid Glass UI** - Modern transparent design language
- **Theme System** - 6 beautiful themes with dynamic gradients
- **Animation System** - Smooth, fluid transitions throughout

## 🚀 **Getting Started**

### **Option 1: Using Xcode (Recommended)**

1. **Open the Project**

   ```bash
   open ModerniOS26App.xcworkspace
   ```

2. **Build and Run**
   - Select your target device or simulator
   - Press `Cmd + R` to build and run
   - Experience the Liquid Glass UI and AI features

### **Option 2: Using Build Script**

1. **Run the build script**

   ```bash
   ./build.sh
   ```

2. **Open in Xcode**
   - The script will build the project
   - Open `ModerniOS26App.xcworkspace` in Xcode 26
   - Run the app on your preferred device

## 🎯 **How to Use**

### **Creating Your First Entry**

1. Tap the "Write New Entry" button on the home screen
2. Add a title (optional)
3. Select your current mood
4. Write your thoughts in the rich text editor
5. Add tags to organize your entry
6. Tap "Save" to store your entry

### **Exploring AI Insights**

1. Write an entry with some content
2. Enable AI Insights in settings
3. View detailed analysis including:
   - Sentiment analysis (positive/negative/neutral)
   - Key topics extracted from your writing
   - Writing style assessment
   - Personalized suggestions

### **Searching and Filtering**

1. Go to the "Entries" tab
2. Use the search bar to find specific entries
3. Filter by mood using the mood buttons
4. Tap any entry to view full details

### **Viewing Statistics**

1. Navigate to the "Stats" tab
2. View comprehensive analytics:
   - Total entries and word count
   - Writing streak
   - Mood distribution
   - Monthly activity charts

### **Customizing Your Experience**

1. Go to "Settings"
2. Choose from 6 beautiful themes
3. Enable/disable AI features
4. Configure voice notes and location tracking
5. Set up daily reminders
